# Portfolio Website with Auto-Documentation

This repository contains my personal portfolio website for **FGCT6012 - Advanced Games Programming: Task 1 Website with Auto Documentation**.

The site is deployed using **GitHub Pages** and uses **GitHub Actions** to automatically generate documentation from a small JavaScript code sample using **JSDoc**. The purpose of the site is to present a simple portfolio landing page, project examples, contact information, and auto-generated technical documentation.

## What's included

- `index.html` — landing page with name, short bio, navigation, and contact link
- `projects.html` — project page with sample portfolio projects
- `assets/styles.css` — consistent visual styling for the website
- `media/` — image assets used by the site
- `src/greeter.js` — small documented JavaScript code sample
- `jsdoc.json` — JSDoc configuration file
- `.github/workflows/pages.yml` — GitHub Actions workflow for building docs and deploying the site
- `docs/setup.md` — setup notes explaining GitHub Actions, GitHub Pages, and where generated docs appear
